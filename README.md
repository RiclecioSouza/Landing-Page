# Landing-Page
Página institucional para uma marca fictícia, apresentando seus produtos e serviços.

## ✨ Sobre o projeto
A CONFS é uma proposta de marca voltada para momentos de prazer, reunindo produtos como:

- ☕ Café
- 🍵 Chá
- 🍦 Sorvete
- 🥤 Milkshake
- 🥣 Açaí
- 🧇 Waffle
- 🍫 Brownie

## 🎯 Objetivo
O objetivo do projeto é criar uma página institucional para apresentar uma marca e seus produtos de maneira visualmente agradável.

## 🛠️ Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript
- Bootstrap Icons

## 🍨 Cardápio
O projeto possui um cardápio dividido em quatro categorias:

### Cafés
- Café Tradicional
- Café Gelado
- Cappuccino

### Sobremesas
- Waffle Especial
- Brownie
- Sorvete Especial

### Bebidas
- Milkshake
- Chá Gelado

### Açaí
- Açaí
- Açaí na Tigela
- Açaí Especial

O cardápio completo é exibido através de um modal, permitindo que o usuário consulte os produtos sem precisar sair da página.
